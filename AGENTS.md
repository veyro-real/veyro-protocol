# Veyro development rules

Build this project independently. Do not import source, setup, contracts, architecture, branding or credentials from unrelated projects. Public platform documentation and normal open-source dependencies are allowed.

Keep testnet execution and mainnet research distinct. Never enable mainnet spending or use real funds as a fallback for test infrastructure. Preserve budget, recipient, program, expiry, nonce and revocation enforcement. Never commit keys, environment secrets, provider credentials or local runtime state.

Make only truthful claims about validation, deployment and financial outcomes. The marketing page and live app are separate Railway services. The live app uses a monochrome Vercel-inspired design with Veyro branding.
